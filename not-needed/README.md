# Archived project material

This directory is intentionally outside the active project documentation and
analysis surface. Do not inspect it unless the project owner explicitly asks
for historical comparison, recovery, or credential-handling work.

Contents may include retired credentials, obsolete context prompts, prototype
snapshots, and stale generated delivery PDFs. Nothing here is authoritative.

Moving a credential here does not revoke it. Credential validity must be
handled through the relevant account or secret-management process.
