# Demo reference files

The PDFs in this directory are local-only visual and terms references for the dynamic
Sales Quotation / Shipment Contract renderer:

- `AAA FORMAT QUOTATION.pdf` — original reference.
- `AAA_FORMAT_QUOTATION_revised.pdf` — newer revised reference.

The revised file takes precedence when the two differ. Neither PDF is loaded
as static application content; quotation fields, currency, totals, terms, and
line items must come from the current record. These supplied PDFs are
NDA/client reference material and are intentionally ignored by Git. Keep them
on the encrypted local workspace and do not expose them through the public demo
route. Only this README is repository-safe.
